כניסה לעריכה

העריכה נשמרת ישירות במאגר הקבצים של האתר, ולכן צריך מפתח גישה אישי מ־GitHub. המפתח נשמר בדפדפן הזה בלבד ולא נשלח לשום מקום אחר.

  1. נכנסים ל־יצירת מפתח אישי ב־GitHub.
  2. ב־Repository access בוחרים Only select repositories ואת מאגר האתר.
  3. ב־Permissions → Repository permissions מגדירים Contents: Read and write, ו־Actions: Read-only (כדי לדעת אם הפרסום הצליח).
  4. מעתיקים את המפתח ומדביקים כאן.

בחרו מימין מה לערוך, או צרו דף או נושא חדש.
