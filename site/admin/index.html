כניסה לעריכת האתר

התחברו עם חשבון Google שקיבל הרשאת עריכה.

העריכה נשמרת ישירות במאגר הקבצים של האתר, ולכן צריך מפתח גישה אישי מ־GitHub. המפתח נשמר בדפדפן הזה בלבד.

  1. נכנסים ל־יצירת מפתח אישי ב־GitHub.
  2. ב־Repository access בוחרים Only select repositories ואת מאגר האתר.
  3. ב־Permissions מגדירים Contents: Read and write, ו־Actions: Read-only.
  4. מעתיקים את המפתח ומדביקים כאן.
