חיבור Workers AI לשרת Node

המתאם ממשיך את שירות תרגום הכותרות הקיים של Cloudflare, בלי להחליף ספק או מודל. הוא כבוי כברירת מחדל. בניית חבילת אתר, בדיקת הגדרות והפעלת שרת אינן שולחות בקשת AI ואינן מאמתות מפתח מול הספק.

החשבון היחיד המותר בקוד: 65aba402e181a43a2657b8a4cd0cfda1
המודל היחיד המותר: @cf/meta/m2m100-1.2b
הפעולה היחידה: תרגום טקסט קצר מעברית לאנגלית דרך ממשק env.AI.run הקיים.

הגדרות הפעלה, רק בסביבת הריצה הפרטית של יישום Node:

CMS_AI_PROVIDER=cloudflare-workers-ai
CLOUDFLARE_AI_ACCOUNT_ID=65aba402e181a43a2657b8a4cd0cfda1
CLOUDFLARE_AI_API_TOKEN=<מפתח ייעודי שהוזן באופן פרטי>

הטקסט בסוגריים הוא מציין מקום בלבד ואינו מפתח. אין להכניס מפתח למאגר, לקובצי האתר הציבוריים, ל-admin/config.json, לארגומנטים של פקודה או לדוחות. המתאם אינו יוצר מפתח ואינו בוחר או קורא אוטומטית CLOUDFLARE_API_TOKEN או מפתחות פריסה קיימים. הרשאות המפתח והחשבון טעונות אימות לפני הפעלה; בדיקת התחביר המקומית אינה מוכיחה שההרשאות תקינות.

כדי להשאיר את השירות כבוי, השמט את שלוש ההגדרות, או הגדר CMS_AI_PROVIDER=disabled ללא שני משתני CLOUDFLARE_AI_*. הגדרות חלקיות, ספק אחר, חשבון אחר או פרטי AI שנותרו לצד מצב כבוי עוצרים את הפעלת השרת עם הודעת הגדרה שאינה מציגה ערכים פרטיים.

מכסות ותקציב:

המסלול /translate נשאר מאומת ומוגבל בקצב. לפני כל פנייה למודל, מנגנון הנתונים הקיים שומר מכסה אטומית: ברירת המחדל היא עד100 בקשות לעורך ועד300 לכל האתר ביום UTC. TRANSLATE_PER_USER ו-TRANSLATE_PER_DAY משנים את המכסות במסגרת הגבולות הקיימים. כשל ספק או זמן המתנה שפג עדיין נחשב ניסיון במכסה; אין ניסיון חוזר אוטומטי. מילון המונחים הקבוע פועל גם כשהמודל כבוי ואינו צורך בקשה למודל.

המכסות הן הגבלת שימוש של היישום, ולא הבטחה לשירות בחינם או לתקרת חיוב בחשבון. לפני הפעלה יש לבדוק את תנאי Workers AI, זמינות המודל, ההרשאות והתמחור בחשבון הקיים. הקוד אינו משנה תוכנית, אמצעי תשלום, הגבלת חיוב או ספק. אין להסיק שאין חיוב מכך שהבדיקות המקומיות עברו.

גבולות הבקשה:

- טקסט עד80 יחידות UTF-16 ועד320 בתים ב-UTF-8, ללא חיתוך נוסף במתאם.
- כתובת API קבועה ב-api.cloudflare.com; אין אפשרות להגדיר כתובת חלופית.
- מפתח רק בכותרת Authorization, ללא cookies; הפניות HTTP נדחות.
- עד10 שניות לכל הבקשה, כולל גוף התשובה. זמן ההמתנה אינו מחודש בין שלבים.
- גוף תשובת ספק עד16KiB; טקסט תרגום עד2048 יחידות UTF-16 ועד4096 בתים.
- תשובה לא תקינה או כשל גורמים לשגיאה כללית בלבד. Worker הקיים מחזיר ללא slug מוצע; פרטי הספק, המפתח והטקסט אינם מועתקים לשגיאות.

דוח ההפעלה מציין slugAiAvailable לפי קיום המתאם ו-slugAiProvider לפי ההגדרה. slugAiVerified נשאר false: ההפעלה אינה בדיקת חיבור לשירות. שמות אלה אינם אישור לתקינות מפתח או לזמינות הספק.

בדיקות מקומיות ללא פנייה ל-Cloudflare:

node --test test/workers-ai.test.mjs test/worker-ai-quota.test.mjs test/node-runtime.test.mjs

הבדיקות מזריקות תעבורת ספק מדומה. הן בודקות את גבולות הבקשה והתשובה, ביטול בזמן, חסימת הפניות, הגדרות חלקיות, היעדר פנייה בהפעלה ושמירת המכסה לפני הפנייה המדומה. אימות חי של חשבון או מפתח דורש פעולה נפרדת שאינה חלק מהבדיקות או מהפעלת השרת.
