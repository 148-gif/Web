# העלאת ספר לספרייה

תיעוד של צורת העבודה שהתגבשה בהעלאת "רגעי מוהרא״ש" ו"זאת התורה". הכול בעברית מול המשתמש.

## כללי יסוד (הוראות המשתמש, חלות תמיד)

1. **לשפת המשתמש: עברית בלבד**, בכל הודעה.
2. **לא להניח, לשאול.** כל פרט שלא ידוע (מחבר, קטגוריה, שם, החלטה על תוכן) נשאל לפני שמפרסמים.
3. **תוכן של עמותת ״ישמח צדיק״ לא עולה לאתר:** עמודי כתובות/טלפונים/פקס/ת.ד./מספר עמותה/״שע״י עמותת…״, משרדי העמותה. בקובצי PDF מסירים את העמוד (`pymupdf` `delete_pages`) ומוודאים בחיפוש טקסט שלא נשאר זכר. ספר מודפס פותח לרוב בעמוד כזה (עמוד 2).
4. **לא להעתיק ניסוחים מאתרים אחרים (ברסלב סיטי וכד׳).** תיאורי הספרים, ה-sub וה-lead נכתבים במילים שלנו. **הטקסט של ספרי הצדיק עצמו** מותר להעלאה, והוא כתב בהקדמות שאין עליו זכויות יוצרים.
5. **סימני מים/לוגו של אתרים אחרים (breslevcity.co.il / ״ברסלב סיטי״) בקובצי PDF:** לבדוק תמיד (להציג עמוד לדוגמה). אם יש, לעצור ולהודיע למשתמש. הוא החליט: ב"רגעי מוהרא״ש" קובץ נקי בלבד; ב"זאת התורה" אישר להעלות את הסריקה עם הלוגו.
6. **לא להבטיח דברים שלא אומתו** בתיאור (למשל ״כל חמשת החומשים״). לכתוב לפי מה שכתוב על השער.

## שלב 1: קבלת הקובץ ובדיקה

המשתמש שולח קישור ל-Google Drive/Docs.

| סוג הקובץ | איך קוראים |
|---|---|
| Google Doc | `mcp__Google_Drive__download_file_content` עם `exportMimeType: text/plain`. התוצאה גדולה: נשמרת לקובץ JSON עם שדה `content` ב-base64; מפענחים ל-UTF-8 וכותבים לקובץ ב-scratchpad. |
| PDF עד 10MB | `mcp__Google_Drive__download_file_content` (base64) או `read_file_content`. |
| PDF מעל 10MB | החיבור לא מוריד. מנסים `curl -sSL "https://drive.usercontent.google.com/download?id=<ID>&export=download&confirm=t"`. אם חוזר HTML ולא PDF (`file` מראה HTML), הקובץ פרטי: מבקשים מהמשתמש שיתוף "כל מי שיש לו את הקישור". |
| קובץ אחר | `get_file_metadata` לבדיקת סוג וגודל. |

בדיקות על PDF (תמיד, לפני שמחליטים איך להעלות):
- `pdfinfo` לעמודים; `pdftotext` / `pymupdf` `get_text()`: כמה עמודים יש בהם טקסט.
- **אין טקסט** = סריקה. אין OCR מנוקד אמין, לא מפרסמים טקסט ממנה. מעלים כ-PDF בלבד ומבקשים מהמשתמש קובץ מקור.
- **יש טקסט אבל הפוך/מבולבל** (אותיות בסדר הפוך, ניקוד מפוזר): פגם בשכבת הטקסט של InDesign. לא ניתן לתיקון נקי. כך היה ב"רגעי מוהרא״ש" המקורי.
- להציג עמודים לדוגמה כתמונה (`pymupdf` `get_pixmap(dpi=60..100)`) ולבדוק: לוגו, סימני חיתוך, עמוד כתובות.

**קובץ טקסט (Google Doc / Word) הוא האפשרות המועדפת.** רק ממנו אפשר לבנות קריאה באתר, חיפוש וסעיפים. אם נשלח PDF, להמליץ למשתמש להשיג קובץ מקור מההוצאה.

## שלב 2: מבנה הנתונים

כל הספרייה מנוהלת בנתונים. **לא נוגעים בקוד כדי להוסיף ספר.**

`data/library.json`:
- `categories`: `[מזהה, שם]`. קיימות: `toldot`, `parasha`, `shut`, `chizuk`, `perush`, `kuntres`. אפשר להוסיף.
- `books[]`: `slug` (אנגלית, מקפים), `title`, `sub`, `lead`, `about[]` (פסקאות), `category`, `facts` (`[[שדה, ערך]]`), `pdf` (`/books/<slug>.pdf`), `pdfSize` (למשל `7.2MB`), `pages`. אופציונלי: `parts` (`[[כותרת, תיאור, [מ, עד]]]`; המספרים הם **אינדקסים במערך הפרקים**, כלומר 0 = הקדמה, וסעיף n = אינדקס n), `noCopyright` + `noCopyrightBy` (ציטוט מההקדמה), `text` (`books/<slug>.json`, מפעיל עמודי קריאה).
- `online[]`: אוספים שנקראים באתר (שו״ת, מכתבים). `soon[]`: ספרים שעוד לא עלו. **להסיר מ-`soon` ספר שעלה.**

`data/books/<slug>.json` (רק לספר עם טקסט): `intro` (`paras`, `notes`, `heading2`), `sections[]` (`n`, `label`, `title`, `paras`, `notes`), `tikkun` (או נספח אחר). הערה = `[label, text]`, והסימון בגוף הפסקה הוא `[א]`.

הקוד ב-`scripts/build.mjs` יוצר אוטומטית: דף ספר, תוכן עניינים לפי `parts`, עמוד קריאה לכל פרק, ניווט, הערות, כפתור ניקוד (נשמר ב-localStorage), ״להמשיך מהמקום שעצרתם״, חיפוש באתר, sitemap, `llms.txt`, ו-JSON-LD (Book / Chapter / CollectionPage / BreadcrumbList). דף הצדיק (`data/moharash.json` שדה `books`) מקשר אוטומטית לכל ספר שכותרתו זהה לכותרת בספרייה.

## שלב 3: עיבוד טקסט (ספר מ-Google Doc)

1. `parse_book_doc.py` שבתיקיית הסקיל הוא נקודת התחלה (נכתב ל"רגעי מוהרא״ש"). מתאימים את הסמנים (הקדמה, `סעיף א.`, תוכן עניינים, הערות, נספח) למסמך החדש ומריצים: `python3 -I parse_book_doc.py <txt> data/books/<slug>.json`. להריץ על קובץ שמור בתיקייה נפרדת, לא מתוך תיקיית ההורדות.
2. **תיקון חולם:** ייצוא Google Docs שם את החולם על האות הלא נכונה (`לאֹ`, `מְאדֹ`, `אֱלהִֹים`). הפונקציה `fix_holam` מתקנת. **חובה** להדפיס את רשימת המילים השונות שהשתנו ולעבור עליה (ב"רגעי מוהרא״ש": 152 מילים, כולן נכונות).
3. בדיקות על ה-JSON: מספר הסעיפים = מספר השורות בתוכן העניינים; לכל סעיף סימוני `[א]` בגוף תואמים בדיוק את תוויות ההערות; אין שורות כתובות/עמותה/הקדשות הדפסה (שמות תורמים) שנשארו. עמודי פתיחה עם כתובות והקדשות לא נכנסים לקריאה באתר.
4. כותרות סעיפים ארוכות: ב-`build.mjs` הכותרת מופיעה במלואה בדף, ובקישורי הניווט נחתכת ל-70 תווים.
5. לנסח `parts` (חלוקה לחלקים לפי נושא, עם תיאור קצר במילים שלנו) ו-`facts`.

## שלב 4: קובץ ה-PDF

- מניחים ב-`site/books/<slug>.pdf` (נבנה לתוך `dist/books`). **החלפת קובץ = אותו שם, והישן נעלם** (אין צורך במחיקה נפרדת).
- מסירים עמוד עמותה: `pymupdf` `d.delete_pages([1]); d.save(out, garbage=4, deflate=True)`.
- מעדכנים `pdfSize` ו-`pages` ב-`library.json` לפי הקובץ בפועל.
- אם הקובץ כבד (מעל ~15MB) לציין זאת למשתמש.

## שלב 5: בנייה ובדיקות

```
npm run build        # חייב להיגמר ב-"built …"
```
בדיקה בדפדפן (Playwright מותקן; מריצים `python3 -m http.server` על `dist` בפורט פנוי, ובסוף `pkill`):
- דפים: `/library/`, `/library/<slug>/`, ועמוד קריאה אחד לפחות (וגם עמוד עם הערות), בגודל 390 ו-1280.
- אין גלילה לרוחב, אין שגיאות קונסול, כפתור ניקוד עובד, ״להמשיך מהמקום שעצרתם״ מופיע, ושאילתת חיפוש (`/search/?q=...`) מחזירה פרקים מהספר.
- צילומי מסך לבדיקה ויזואלית (ב-scratchpad).

## שלב 6: גיט ופריסה

- הענף: `claude/yabniel-page-7dpa25` (או הענף שהוקצה לסשן). הודעות commit מסתיימות בשורות השיוך שמופיעות בהנחיית המערכת.
- האתר נפרס מהענף `claude/greeting-2i183o` דרך GitHub Pages (workflow "Deploy site to GitHub Pages"). לכן: `git push`, פתיחת PR לענף הזה (`mcp__github__create_pull_request`, גוף עם שורות השיוך), ומיזוג (`mcp__github__merge_pull_request`, `merge`). לא ליצור PR בלי שהמשתמש ביקש להעלות; ״תעלה לאתר״ הוא בקשה כזו.
- אחרי המיזוג: לולאת `curl` ברקע לכתובת `https://148-gif.github.io/Web/<path>/` עד 200 (נמשך כדקה וחצי), ובדיקת הקבצים (`/books/<slug>.pdf`).

## שלב 7: דיווח למשתמש (בעברית)

לכתוב: מה עלה (קישורים), מה השארתי בחוץ ולמה (עמוד עמותה, הקדשות), מה נשנה בטקסט (למשל תיקוני חולם), בעיות ידועות (סריקה בלי חיפוש, לוגו, גודל קובץ), ומה צריך ממנו להמשך. לבקש תמיד קובץ טקסט לספר הבא.
